# Domain Overview

## Purpose

This MVP supports **admin staff** and **teachers/mentors** who manage attendance-driven operations in an education setting. It focuses on class-group attendance and 1:1 mentorship delivery that is billed by lesson credits.

## Primary Users

- **Admin staff:** manage master data, set up class groups, oversee enrollments, and keep records accurate.
- **Teachers/Mentors:** run lessons or mentorship sessions and record attendance.

## Core Flows

1. **Master Data Management**
   - Create and maintain students, teachers/mentors, and subjects.
2. **Class Groups**
   - Create class groups, enroll students, generate lessons, and capture attendance.
3. **Mentorships (1:1)**
   - Create mentorships with a single student, schedule sessions, record attendance, and log credit-based payments.

## Scope Boundaries

- **In scope:** class-group attendance, mentorship session attendance, mentorship credit-based payments.
- **Out of scope:** class-group monthly billing (handled outside the system).

## Glossary

- **Class Group:** A cohort of students taking lessons together.
- **Enrollment:** A student’s membership in a class group.
- **Lesson:** A scheduled class-group meeting.
- **Attendance:** Presence records for lessons or mentorship sessions.
- **Mentorship:** A 1:1 engagement between a mentor and a single student.
- **Session:** A scheduled mentorship meeting.
- **Payment/Credits:** Credit-based billing entries for mentorship sessions.
