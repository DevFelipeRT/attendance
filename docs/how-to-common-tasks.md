# Common Tasks

## Manage Master Data

- **Students:** add, edit, or remove students before enrolling them in class groups or mentorships.
- **Teachers/Mentors:** maintain the staff list used to assign class groups and mentorships.
- **Subjects:** keep subjects up to date for scheduling class groups.

## Run a Class Group Workflow

1. Create a class group and assign a teacher and subject.
2. Enroll students into the class group.
3. Generate lessons for the class group.
4. Record attendance for each lesson.

## Run a Mentorship Workflow (1:1)

1. Create a mentorship with a single student and a mentor.
2. Schedule mentorship sessions.
3. Record attendance for each session.
4. Register credit-based payments and debits as needed.
